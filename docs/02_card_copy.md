## 1. 行动类型风味语（每种一句）

| 行动类型 | 风味描述 |
|---|---|
| 扬帆 sail | 升帆、转舵、抢风——潮汐不等人，先到的船先挑货。 |
| 市集交易 trade | 码头上的吆喝声此起彼伏，一枚金币的差价就是一天的盈亏。 |
| 交付订单 deliver | 契约上盖着商会的火漆印，按时交货的人才有下一单生意。 |
| 设立商站 post | 打下第一根桩，挂上商会的旗——这条街从今天起有你的席位。 |
| 潮汐秘术 tidecraft | 老水手听得懂海的呼吸，而秘术师能让海改一改主意。 |
| 顺风 tailwind | 抓住一阵好风，船未靠岸，生意已经谈成了。 |
