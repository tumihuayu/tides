# 《潮汐商会》美术方向 v1.0

## 1. 总体风格

**「潮雾群岛 · 商会航海 · 轻奇幻」**

- **潮雾群岛**：低饱和的海雾、礁岩与木质栈桥构成世界基底；海面永远是画面的第二层主角，潮汐状态必须一眼可读。
- **商会航海**：账房、火漆印、货筐、铜秤、旗帜——贸易的"实感"道具优先于魔法特效，让游戏首先是"做买卖"，其次才是"有秘术"。
- **轻奇幻**：奇幻浓度控制在 10%：潮汐秘术的微光、丝贝的虹彩、海雾中隐约的发光生物。不画龙、不画大型海怪，避免题材跑偏成冒险游戏。

参考气质关键词：水彩厚涂混合、版画风海图、暖木色+冷海色的昼夜交替感。

## 3. 船长立绘设定（4 名）

### 3.1 阿汐·东鳞（Axi Donglin）—— 务实派船东
- 性格：精明、守时、信账不信命；口头禅"秤不会骗人"。
- 身份：东鳞港本地船队出身，商会账房推选的代表。
- 视觉关键词：靛蓝短打、算盘挂腰间、铜框圆镜、船形发簪；站姿微前倾，像在验货。
- 主色：汐金 + 潮雾蓝灰。

### 3.2 礁叔（Uncle Reef）—— 老水手
- 性格：沉默、直觉派、信潮不信人；年轻时在碎星礁沉过船。
- 身份：跑单帮三十年，最懂暗礁与洋流。
- 视觉关键词：盐渍白胡、油布斗篷、藤壶纹身的左臂、缺角的旧罗盘；总是半侧身望着海。
- 主色：滩涂褐 + 雾白。

### 3.3 雾弦（Wuxian）—— 听潮秘术师
- 性格：飘忽、话少、说半句留半句；坚信"潮有耳"。
- 身份：雾门出身的听潮者，能以铃音"请潮"。
- 视觉关键词：暮紫长袍缀贝壳风铃、银白长发遮一目、指尖萦绕淡青潮光、赤足；半身像被海雾吃掉下缘。
- 主色：暮潮紫灰 + 涨潮青。

### 3.4 白珞（Bailuo）—— 新晋商会千金
- 性格：张扬、好胜、讨厌被叫"大小姐"；把贸易当竞技。
- 身份：白汐城织造坊继承人，自带丝贝货源。
- 视觉关键词：虹紫披风内衬丝贝纹、高筒航海靴、镀金望远镜、旗语手套；动态定格在挥旗下令的一瞬。
- 主色：贝虹紫 + 汐金。

> 立绘规格：半身像，4:5，透明底 PNG；正面对称构图，便于裁剪为圆形头像（对局内）与竖版卡（选角/宣传）。

## 4. 图标设计说明

### 4.1 货物图标
- 统一 1:1 圆形徽章底，线稿 2px，平涂+单阴影。
- 盐鳞：三片菱形鳞叠成品字形，白色勾金边。
- 灯油：圆腹油罐，罐口一撮火苗（琥珀渐变）。
- 丝贝：张开的扇贝中含一缕丝状虹光。
- wild：上述三形以 120° 旋转叠印，中心一颗四角星。

### 4.2 港口图标
- 东鳞港 east：鱼鳞纹屋顶的栈桥市集，旗杆挑灯。
- 碎星礁 reef：三座尖礁环一湾，礁尖各嵌一颗发光"星砂"。
- 雾门 fog：两柱天然石拱门，门中垂落雾帘。
- 白汐城 white：白墙高塔群+大钟楼，屋顶一律朝海倾斜。
- 版图表现：四港按环形相邻关系画在同一张潮雾海图上，港间以虚线航路连接。

### 4.3 卡框
- 牌面三段式：顶部**行动条**（行动图标+名称），中部**插画窗**，底部**双用条**（左：货物徽章；右：潮纹贝壳格，0 或 1 格点亮）。
- 六种行动各配一个角标小图标：扬帆=帆、交易=天平、交付=火漆印、设站=旗帜桩、秘术=潮纹漩涡、顺风=风旋。
- 卡背：四港海图压纹 + 中央潮汐四相徽记。

### 4.4 标记
- 船位标记：俯视小帆船木 token 造型，四玩家配色（金/红/青/紫）。
- 商站标记：小旗插桩造型，与船位标记同色系；港口计分区预留 4 个桩位槽。
- 潮汐轨道标记：一枚"月相圆片"，在四格轨道（滩涂/浪升/满月/雾退图标）上滑动。
- 价格轨标记：铜砝码造型，在 1-6 刻度上移动。
