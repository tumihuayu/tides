# docs/ 文档索引

`docs/` 保存玩法、规则、美术和界面设计资料。实现联机行为时，先以 [`shared/protocol.md`](../shared/protocol.md) 和 `shared/data/` 为准；本目录用于解释设计意图、规则和验收背景。

| `03_balance.md` | 数值和平衡 |
| `04_art_direction.md` | 美术方向 |
| `05_ui_spec.md` | UI 规格 |

| `10_new_player_tutorial_v1.0.md` | 新手教程 |
| `11_page_flow_and_ui_design_v1.0.md` | 页面流程与 UI 设计 |

| `13_leave_game_rage_quit_v1.0.md` | 退出对战与强退规则 |

新增玩法或修改规则时，同时更新规则文档、`shared/data/`、`shared/protocol.md`（如涉及协议）和对应测试计划。
